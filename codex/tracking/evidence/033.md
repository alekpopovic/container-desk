## Remaining limits

- Native execution was Linux x86_64 on Ubuntu 26.04.1/X11 only. No macOS, Wayland, Ubuntu 24.04 baseline, package-install or signing/notarization proof.
- Permission denial is deliberately injected by the owned gate, not a Docker authorization plugin. Daemon drift regression uses a controlled probe projection; it is not an actual Engine replacement.
- Pending cancellation can race with a dispatch already admitted; dispatched commands finish or time out and retain their result. Docker may independently refuse a state change after the final read. Local activity is bounded and editable, not an audit log.
- Official Docker removal options checked at https://docs.docker.com/reference/cli/docker/container/rm/ on 2026-09-29. No production alias or resources used.
- No remaining blocker for 033. The environment's default shell sandbox is broken (bubblewrap mountinfo); authorized commands ran through the available reviewed execution path.
