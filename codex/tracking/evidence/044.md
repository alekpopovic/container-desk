## Changes

- Shared native modal component replaces five non-modal action/paste confirmations. Cancel receives initial focus, Tab cycles inside, Escape cancels before dispatch, and focus remembers the invoker before asynchronous preparation disables it. Existing support/log-export dialogs share the Tab boundary handler; busy export cannot silently close via Escape.
- Linux Ctrl / macOS Cmd shortcuts for search and current resource refresh, Shift+H for host selection and Shift+L for the Logs tab. Handler ignores composing/repeated/alternate-modifier events, open modals and all terminal controls. Refresh invokes only the existing enabled read button. No mutation/terminal input retry, privilege or transport changes.
- Container tables retain bounded virtualization and gain an optional 24-row paged mode with explicit navigation for keyboards/readers. Tables/logs have focusable scroll regions. Fonts, table width and row calculations follow rem size via a cleaned-up ResizeObserver. Reduced-motion media rules disable animation, transitions and smooth scrolling. Fixed dialog theme color, large-text brand/group wrapping and scaled column widths.
- Added targeted UI checks, actual release keyboard/Orca harness, and [keyboard/audit documentation](../../../docs/accessibility.md). Historical evidence and original task hashes remain unchanged.

## Acceptance criteria and audit

- Keyboard-only host → container → logs: actual X11 key events after disposable saved-host setup. Select saved host, explicitly connect, search full ID, select row, focus Logs, start/pause and scroll. DOM writes are limited to event instrumentation and the later theme/text-size inspection; they never focus, click or dispatch the journey.
- Screen reader: actual Orca announces at least two allowlisted native controls through AT-SPI. Only allowlisted label matches are retained; raw debug output exists solely inside the temporary owned session. This verifies speech generation, not audible quality or broad screen-reader compatibility.
- Native modal: at 200% text, keyboard navigation opens the support confirmation on Cancel; Tab/Shift+Tab remain inside, Escape closes and restores the trigger. No history clear is dispatched. Browser tests also verify mutation cancellation without dispatch and terminal multiline paste behavior.
- Semantics: resource tables retain captions/scoped headers and selected/sorted state; console tabs retain roving arrow navigation. State/error labels accompany color. Status/alert regions announce connection/action changes; raw logs are not an application-wide live region.
- Large data/text: all 1,000 rows reachable through 24-row pages; final page 985–1000 selectable. Font size doubled to 175% root (normal 87.5%) at 1280×800, 800×700 and 640×480, both themes, with contained horizontal table scrolling and no document overflow. Native WebKitGTK separately inspected at 100% and 200% text. This is text resizing, not evidence for OS display scaling.
- Theme/reduced motion: existing foreground/muted/accent/state contrast assertions pass (4.5:1 text; 3:1 focus). Reduced-motion emulation passes the keyboard/layout checks; corresponding CSS is explicit.
- Bounds/security: no backend permission, process ownership, quoting or identity changes. The real streaming lab additionally verifies bounded delivery (128-record batches), explicit drop markers, stop/reaping and loss under load, with unchanged strict SSH trust on both owned hops.

## Verification corrections and remaining limits

Early checks found a JSX closing-tag error, an incomplete hash comparison that prevented deferred focus, focus lost while asynchronous preparation disabled the invoker, and browser Tab traversal reaching outside the native dialog. These were corrected before acceptance. A fixture control formerly clicked behind a confirmation now sets its hold before opening the modal. Native typing initially raced the first inventory mount; the final harness waits for the actual three-container snapshot and sends paced native keys. A pre-existing skip-link test sent its first Tab before React mounted; it now waits for the link to exist without moving focus. Screenshot review corrected clipped group/brand names and overly narrow large-text table columns. Failed attempts are not counted as acceptance.

Linux X11 only. Native macOS shortcuts/VoiceOver, Wayland, OS display-scale combinations, installed packages and signing are not verified here. This is a targeted accessibility audit, not WCAG certification. Resource search and explicit paging remain the supported means to reach virtualized rows; non-rendered rows are not claimed to exist in the accessibility tree. All laboratory keys/configuration, reader debug files and session data are app/test-owned temporary resources; no production alias was used.
