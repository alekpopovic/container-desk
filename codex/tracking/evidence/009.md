## Changes

- Added SSH discovery module with bounded regular-file reads, literal aliases, multiple Host tokens, comments/quotes/equals syntax, Include references/globs, canonical cycle detection and explicit typed warnings.
- Default config path comes from the native home-directory resolver. Relative user includes are based on ~/.ssh. Conditional/dynamic discovery remains conservative and has a manual alias path.
- Centralized the existing alias subset in Rust and reused it for persisted host validation. New config/selection/discovery DTOs and three narrow IPC handlers are generated and granted to the main window.
- Added Settings candidate browsing and manual selection. No automatic read/scan/connection, no config rewrites, no effective resolution yet. Selected alias/path form an in-memory draft; host inventory persistence is later work.
- Discovery uses a blocking worker holding its own single-flight permit, retained even if its caller goes away. Demo denies discovery and selection at the backend and mode changes cannot race active discovery.
- Updated shared IPC fixture, focused Node/browser tests and docs/ssh-discovery.md. No new dependency or lockfile change.
