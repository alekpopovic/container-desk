## Verification corrections

Initial native testing exposed a real failure: a lost fresh Docker probe was classified as daemon drift, forcing manual disconnect and preventing recovery. Central transport classification fixed it; actual daemon changes still reject as stale. WebDriver session deletion did not establish native exit and initially left owned SSH children; the final test uses an actual window close, an Exit cleanup backstop, and checks native exit before driver deletion. Failed attempts were not counted as acceptance.

Harness corrections wait on hidden connection status via textContent, stop log rendering before trusted keyboard tab activation, wait for an actual remote shell prompt, and compare PID start times including zombie detection. One WebDriver disconnection and missed coordinate clicks were failed attempts. The final complete run additionally holds an actual stats command at every fault, rather than inferring activity from a mounted component. Both resulting screenshots were visually reviewed.
