## Changes

- Added finite-read scheduler used by actual inventory/inspect/log-snapshot/stats IPC adapters. Full request identity scopes single-flight sharing; separate consumer lifetime checks cancel queued work, suppress late publication and stop stale retries.
- Limits: 3 host/daemon groups, 16 unique outstanding jobs per group, 32 consumers per job; 2 active reads per group, 1 background stats read and 4 finite reads globally. User reads precede queued stats. Dispatched reads retain their slots until completion.
- Only three transient read errors retry, at most 3 total dispatches, with exponential 500/1000 ms bases and 75–125% jitter, monotonic deadlines and bounded scheduling scans. All mutation/terminal/export/stream paths remain outside this scheduler.
- Extracted native host admission guards shared with existing stats: 2 finite reads per saved host, 1 stats read per host, existing 4 native permits including streams. Guards release on errors/cancellation without renderer cooperation.
- Added selected-scope focus/visibility/network and suspended-clock snapshot recovery through the existing event invalidator. Retained existing authoritative cache, last-success timestamps, stale/empty/disconnected distinctions and selection-only inspect behavior.
- Added measured fake-clock/IPC tests and owned slow-read native SSH acceptance. Native screenshot framing waits for detail loading and repositions after asynchronous layout changes. Design: `docs/read-scheduling.md`.
