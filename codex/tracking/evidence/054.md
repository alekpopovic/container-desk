# 054 — macOS application and DMG builds (in progress)

Started after completed 053. Existing native arm64/x86_64 macOS 15 runners and pinned toolchains are reused. Packaging now requests both app and DMG, retains the ordinary-binary verification gate, and records both packages/checksums. Bundle identity remains dev.containerdesk.app, minimum macOS 15.0; the existing PNG icon is used by Tauri. DMG configuration specifies the app and Applications-folder positions.

Native GUI access is being probed on both hosted runner architectures without changing OS access controls. Actual DMG/contents/Finder launch/app-data/agent/OpenSSH acceptance is pending. Builds alone will not be counted as that evidence. No signing credentials, public publisher or release write permission is added.
