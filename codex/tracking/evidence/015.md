## Acceptance criteria

- Reuse: three inert reads on both direct and ProxyJump routes return the same server-observed TCP tuple; cancelling a concurrent sleep leaves that connection usable. A real remote PTY channel shares it. Closing the connection cancels two other owned channels and removes the owned socket.
- Shutdown/user master: a deliberately source-configured independent master has a different TCP tuple. The app's production session coordinator starts its own connection, then the same shutdown method used by the Exit callback completes native cleanup and restores its gate; the independent master still answers check. Backend shutdown separately rejects new native work. This exercises native backend shutdown, not manual GUI exit.
- Stale socket/fallback: unexpected synthetic stale socket is retained; connection reports DirectFallback; two successful reads use distinct TCP connections. Browser test verifies visible explanation. No arbitrary socket is adopted or exited.
- Long path/permissions: source config path exceeds 240 bytes while private socket stays at most 80; directory 0700 and native socket 0600 verified on Linux.
- Master death: after the app master exits, the next command fails without native implicit reconnection or replay. Idle expiry tested with a two-second test parameter through the production builder, both without monitoring and with monitoring; production remains fixed at 60 seconds.
- Recovery: local real Unix socket tests preserve live flock/listener and unknown/replaced entries, then remove only recognized abandoned dead resources. Native lab confirms original config/trust hashes unchanged and no askpass invocation. Driver removes exactly owned containers/network/agent/temp keys.
