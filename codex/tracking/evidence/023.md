## Changes

- Added typed transient log records, validated range/tail, static driver error, generated contracts, live authorized backend/session adapter and frontend scope/bounds decoder.
- Added dedicated 8 MiB-per-channel log capture without relaxing ordinary diagnostic stderr bounds. Retention is 20,000 records/8 MiB combined; records cap at 256 KiB with truncation/invalid-UTF-8 markers. Stderr is explicitly ambiguous.
- Added meaningful parser, range, retention, IPC and native backend tests. Added an owned loopback SSH laboratory accessing only two disposable container IDs on the explicit local Engine.
- Implementation decisions and lab isolation are documented in `docs/log-snapshots.md`. No new dependency, application persistence or log UI was added.

## Remaining limits

- Snapshot presentation and live streams belong to later prompts. Capture over 8 MiB on either channel reports a resource error; it is not silently clipped.
- Timestamp merge does not prove original cross-channel arrival order. All stderr remains ambiguous. Driver errors with different wording use a safe generic error.
- macOS/Wayland/packages and native GUI logs remain unverified here. This lab uses actual native Linux OpenSSH/backend with a fixture-only forced-command gate and real local Engine; it does not prove additional remote distributions.
- No 023 blocker remains. Synthetic CLI oracle files were temporary test evidence, not application persistence.
