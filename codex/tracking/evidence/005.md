## Changes

- Added schema-2 DTOs and SettingsStore with an injectable Storage trait, file adapter, validation/migration, recoverable previous bytes and corrupt-original archives.
- File writes use private exclusive temporary files, fsync/rename/directory fsync; directory 0700 and files 0600, regular-file/ownership/link checks, nonblocking process lock, 1 MiB bound. Original files survive invalid/future schema and failure paths. Revision checks reject stale updates.
- Persist only aliases, display metadata/groups/labels, independent per-host read-only modes, selected-host reference, theme and trusted config/executable path references. Unknown fields are rejected; no SSH contents are read or copied.
- Backend initialization uses Tauri app_data_dir; list_hosts reads saved metadata. New get_preferences/set_theme commands and scoped capabilities power real theme persistence and visible recovery/error notices. No generic settings-file/executable API.
- Reused generated DTO method and shared fixtures from 004. Added libc 0.2.189 as a direct exact dependency for Unix file flags/locking (already present in Cargo.lock). Added filesystem, fault-injection, IPC and browser checks; storage documentation and native screenshots.
