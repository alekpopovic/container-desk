## Changes

- Added a backend support-report allowlist: build/platform, native transport policy/mode, typed staged errors, counts, report-local host/path pseudonyms and bounded 100-ms timing buckets. No raw DTO, exception text, identifiers, SSH config, key, environment, logs, terminal or inspect payload is serialized. Unavailable sources yield typed source errors rather than preventing all reporting or guessing configuration.
- Added one in-memory preview (64 KiB, five-minute validity), random frozen identifier, explicit native Save/Cancel, and exact private atomic file export through the existing writer. Save accepts only the preview identifier; neither renderer text nor a renderer-chosen path can replace the reviewed content. Replacement, expiry, save and clear invalidate old previews. No automatic upload or write retry.
- Added confirmed clearing of local troubleshooting history and prepared reports. The backend excludes active activity owners and concurrent save dialogs/writes. Existing history remains capped at 200 records/512 KiB; reports show the latest 20. No age-based deletion or new persistent diagnostic text log is introduced. This policy is explicit in the UI/docs.
- Clear scope is troubleshooting history/report, not a factory reset: saved host preferences, SSH files and user exports stay under their existing controls. The action never traverses ~/.ssh. Failed persistence preserves in-memory history.
- Added generated DTOs, three exact Tauri command/capability grants, accessible text preview/confirmation, focused privacy/lifecycle/IPC checks, native export/clear automation and `docs/support-reports.md`.
