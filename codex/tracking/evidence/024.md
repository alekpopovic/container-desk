## Changes

- Added typed follow/ack commands, narrow main-window ACL entries, random owned subscription IDs and exact full-scope authorization/cancellation. Follow validates and pins Docker identity/endpoint before dispatch; detected identity drift revokes the session.
- Added separate-pipe, non-PTY streaming to the shared owned native process runner. Partial lines, retained records, bytes, stream/read slots and Tauri batches are bounded. Acknowledgments allow one IPC batch in flight and expire after 30 seconds.
- Added explicit dropped-record/gap markers, transient minimal Start/Stop preview and best-effort timestamp resume. Unmount cancels even a late successful subscription start. Backend cancellation returns after child reaping and permit release.
- Added real process stress/expiry tests, IPC concurrency tests, browser fixtures and a native release journey with actual event-loop starvation. Extended the owned lab only for exact fixture IDs and deliberate loss of its temporary SSH server. Design is `docs/live-log-streams.md`.

## Acceptance criteria

- Owned host/session/container subscription over typed Tauri channels: PASS actual release channel and strict scope/sequence IPC tests.
- Bounded queues/retention with visible drop marker during slow consumption: PASS measured local process queues, independent actual native backend two-second ACK pause and actual webview 1.8-second event-loop stall. The measurements bound retained content and queue counts, not a claim that whole-process RSS equals text bytes.
- Cancellation under heavy output and network loss without orphan SSH children: PASS owned runner reap acknowledgment and permit release; local process PID absence; actual native SSH server loss independently cancels streams while renderer withholds ACK. Shutdown/unmount and partial oversized line cases also covered.
- Reconnect is best-effort, timestamp resume and visible gaps: PASS explicit native Stop/Start. No automatic reconnect, perfect deduplication or lossless cross-channel ordering is promised.
- Plain transient data and architecture boundaries: PASS separate stdout/stderr, no PTY, pinned command/endpoint, strict client trust unchanged, no raw synthetic log in app storage/diagnostics. Owned laboratory containers, keys and server are cleaned; no unrelated Docker resource is mutated.
