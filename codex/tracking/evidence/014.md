## Changes

- Added a Rust-owned selected connection coordinator, generation/token validation, all seven requested states, three bounded stage-duration entries and static stage diagnostics. The original unused connected/reconnecting/failed enum was replaced consistently, including generated/demo DTOs.
- Native stages use existing bounded resolution/authentication and wait for Runner cleanup before releasing the shared diagnostic gate. Cancellation/switch invalidates the old generation before signalling and joining its worker. Duplicate active connects are idempotent; competing control calls are rejected instead of queued.
- Added begin/get/disconnect IPC, native demo-mode denial checks and Settings progress/cancel/disconnect UI with one-inflight polling and late-response/lifetime guards. Selecting aliases/launching remains nonconnecting; no transient state is persisted.
- Separated authenticated remote command failure from SSH transport/auth failures using the remote status/marker; added a fixture key with a forced exit 7 to the real lab.
- Documented implementation and intentional pre-Docker degraded state in `docs/connection-state.md`.
