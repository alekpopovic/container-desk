## Publication procedure and preserved boundaries

The existing Git/SSH credential created the exact annotated tag; creating the draft from that existing tag without an unnecessary target parameter succeeded. GitHub's [workflow-scope rule](https://github.blog/changelog/2023-11-02-github-actions-enforcing-workflow-scope-when-creating-a-release/) informed diagnosis. No OAuth scope was added, token printed or global active account switched.

Owner commit `c2464b8` disabling Actions is preserved. No publishing workflow, indirect publisher script, token permission or updater was installed; this was a manually authorized release. Source/docs updates preserve all original tracker prompt/evidence hashes. The local candidate remains ignored generated output; installers are release assets, not Git blobs.

## Installation and remaining limits

Linux users select deb or AppImage; Mac users select the DMG matching ARM/Intel, with app archives offered as alternatives. The release body and updated [Serbian quick start](https://github.com/alekpopovic/container-desk/blob/main/README_SR.md) contain checksum/install instructions. Mac ARM is linker ad-hoc, Intel unsigned; neither is Developer ID signed/notarized. Normal downloaded Gatekeeper acceptance is unverified and may be blocked. Linux is unsigned. Public availability does not change these facts or the dependency/platform limits in [release notes](../RELEASE_NOTES.md).
